# Relay inbox

This branch exists only so the "Relay inbox" pull request can stay open. Never merge it.

AI Relay Office posts each handoff as a comment on that PR. A Claude Code session subscribed to the PR wakes up, does the work, and replies on the same PR. The app shows the reply as the CLAUDE NPC.

To connect a new Claude Code session, tell it: "subscribe to the relay inbox PR in cesarmateotkd-sketch/agentic-models".
